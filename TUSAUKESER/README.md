# ТҰСАУКЕСЕР — Remotion монтаж жобасы

Петропавл қаласындағы тұсаукесерге арналған **ұлттық киімдер прокаты** — 25 секундтық сатылымдық Instagram Reels.

- Формат: 9:16, **1080×1920**, **30 FPS**, 25 сек (750 кадр)
- Стиль: Premium Kazakh Motion, cinematic, анимациялық субтитрлер

## Папкалар
| Папка | Не салынады |
|---|---|
| `videos/` | бастапқы видеолар (.mp4, .mov) |
| `photos/` | киім фотолары (.jpg, .png) |
| `audio/` | дайын қазақша озвучка (.mp3) |
| `output/` | дайын монтаж (видео + обложка) |
| `src/` | Remotion коды (Claude өзі жазады) |

## Күйі
Жоба құрылымы дайын. Монтаж әлі басталған жоқ — файлдар жүктелгеннен кейін: сұрақтар → раскадровка → мақұлдау → рендер.
